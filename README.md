# Домашня робота: Асинхронний JavaScript та Проміси

## Що було зроблено в межах завдань:

### Завдання 1. Таймер зворотного відліку (`1-timer.html`)

- Створив інтерфейс таймера, який рахує дні, години, хвилини та секунди.
- Підключив бібліотеку **flatpickr** для зручного вибору дати й часу через
  календар.
- Реалізував валідацію: якщо обрати дату в минулому, кнопка "Start" залишається
  неактивною, а бібліотека **iziToast** показує червоне віконце з попередженням.
- Коли вибирається дата в майбутньому — кнопка активується. Після натискання
  "Start" інпут і кнопка блокуються, щоб користувач не міг нічого зламати під
  час відліку.
- Написав функцію `addLeadingZero`, яка додає `0` попереду чисел (наприклад,
  замість `5` секунд виводиться `05`).

### Завдання 2. Генератор промісів (`2-snackbar.html`)

- Створив форму, де можна ввести затримку в мілісекундах та обрати фінальний
  стан промісу за допомогою радіокнопок (_Fulfilled_ або _Rejected_).
- Написав функцію-генератор `createPromise`, яка повертає новий проміс із
  `setTimeout` всередині.
- Обробляю результат через класичні методи промісів: успішне виконання потрапляє
  в `.then()`, а відхилення — в `.catch()`.
- Замість звичайних логів у консоль підключив спливаючі сповіщення **iziToast**,
  які з'являються на екрані рівно через вказаний час затримки.
